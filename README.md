# Walmart Sales Forecasting Using Machine Learning

A Machine Learning-based retail sales forecasting project that analyzes historical Walmart sales data and predicts weekly sales using **Linear Regression**.

The project uses Python, Pandas, NumPy, Scikit-learn, Matplotlib and Streamlit to perform data analysis, visualize sales trends, and generate sales predictions through an interactive dashboard.

### Key Features
- **Sales Dashboard:** Displays total stores, departments, total sales and average sales.
- **Sales Analysis:** Analyzes store-wise and department-wise sales performance.
- **Data Visualization:** Displays weekly sales trends and top-performing stores and departments.
- **Sales Prediction:** Predicts weekly sales based on store, department, date and holiday information.
- **Machine Learning:** Implements Linear Regression for sales forecasting.
- **Model Evaluation:** Uses MAE, MSE, RMSE and R² score.
- **Data Preprocessing:** Handles missing values, date extraction and categorical encoding.

### Technologies Used

1. Dashboard

### Project Objective
To help retail businesses understand historical sales patterns, forecast weekly demand, improve inventory planning and support data-driven business decisions.
